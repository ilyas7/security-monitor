# Security Monitor Dashboard

Dashboard untuk monitoring keamanan dari file access.log

## Fitur

- Deteksi SQL Injection, XSS, Brute Force, dan lainnya
- Dashboard interaktif dengan chart
- Mapping ke MITRE ATT&CK
- Analisis risiko IP
- Export ke CSV dan JSON

## Cara Menjalankan

### 1. Install Python
Download dan install Python dari https://python.org

### 2. Clone
```bash
git clone https://github.com/ilyas7/security-monitor.git
cd security-monitor

### 2. Usage
```bash
streamlit run src/security_monitor.py
